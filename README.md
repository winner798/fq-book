# FC-BOOK：零基础网络、代理与服务器实践

本仓库由原《这本书能让你连接互联网》整理而来。面向已经会使用简单代理客户端，但希望从原理到服务器完整链路系统学习的读者。

## 建议的学习顺序

1. [课程总路线](docs/course/00-roadmap.md)
2. [网站访问与 DNS、IP、TCP、TLS](docs/course/01-web-journey.md)
3. [代理、VPN、TUN 和分流](docs/course/02-proxy-vpn.md)
4. [服务器、VPS、Linux、SSH](docs/course/03-server.md)
5. [完整客户端—服务器链路实验](docs/course/04-lab.md)
6. [Windows / Android 客户端](docs/course/05-clients.md)
7. [排障](docs/course/06-troubleshooting.md)
8. [进阶与毕业项目](docs/course/07-advanced.md)
