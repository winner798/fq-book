# 从零开始：学习路线

你已经能导入代理配置，但还不清楚为什么需要服务器、域名、端口和证书。本课程以**理解一条完整网络连接**为主线。

## 学习方法

每课按：问题 → 直觉 → 术语 → 数据流 → 实验 → 排障 → 自测。先掌握原理，再操作；所有实验仅在你有权限的设备与服务器上完成。

## 七个阶段

1. 互联网基础：IP、DNS、路由、端口、TCP/UDP、TLS。
2. 代理与 VPN：正向代理、SOCKS、TUN、分流。
3. Linux 服务器：VPS、SSH、防火墙、服务。
4. 完整链路：客户端—代理入口—远端服务器—目标站点。
5. Windows / Android 客户端配置。
6. 排障：分层验证、DNS、路由、证书和日志。
7. 进阶：WireGuard、反向代理、Docker 与维护。

**毕业目标**：能够画出流量路径，独立解释每一跳，搭建合法授权的实验链路并定位故障。
