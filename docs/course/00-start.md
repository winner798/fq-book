# 00｜从这里开始：一条真正适合零基础的路线

> 你的起点：会在手机或电脑上导入订阅、切换节点、打开代理软件，但对网络怎样流动、服务器为什么必要、出错如何定位还不清楚。本课程专门从这个起点讲起。

## 先建立一张地图

这不是“复制几十行配置就算学会”的教程。整个学习过程围绕一个问题：**当你打开一个网页，一条请求究竟经过了哪些设备、软件、网络以及服务器？**

```text
你（浏览器/App）
  → 操作系统（DNS、路由、网络接口）
  → 家用路由器/移动网络
  → 运营商与互联网
  → 目标网站的服务器
  ← 响应沿网络路径返回
```

启用代理后，可能变成：

```text
浏览器/App → 本地代理客户端 → 远端代理服务器 → 目标网站
                             ↑
                        认证/加密/转发
```

**关键区别**：代理客户端不是远端代理服务器；本地“7890 端口”也不是网站的端口。能记住这两个区别，就已经迈出重要一步。

## 每课怎么学

1. **先看生活类比**，解释“是什么”；再追踪一个真实网络请求，解释“为什么”。
2. **画出数据流**：每一段写出出发点、终点、使用的协议和端口。
3. **做小实验**：无需一开始购买服务器，前五课大多可在现有设备上完成。
4. **做课后自测**：能说出“为什么”，而不是背答案，才算过关。
5. 每完成 3～4 课再做一次综合复盘。

## 准备什么

- Windows 电脑或 Android 手机；能看到当前联网方式。
- 一个浏览器；Windows 推荐 PowerShell，Linux/macOS 用终端。
- 已有的可信代理配置可用于第 05 课；**不要把真实订阅、密码、私钥、服务器地址公开到 GitHub**。
- 第 06～08 课需要你自己管理的一台 Linux 虚拟机或 VPS。先理解原理，**不要为了跟教程而急于付费**。

## 三条安全原则

**不关闭证书校验、不为了“通网”关闭系统防火墙、不执行来源不明的一键脚本。** 在不同地区使用相关网络技术应自行遵守适用法律、学校或公司的网络政策。
