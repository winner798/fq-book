# 第六课：系统排障

按 DNS → 路由 → TCP/UDP 端口 → TLS → 应用协议 → 日志依次验证。

| 现象 | 排查重点 |
|---|---|
| 域名不解析 | DNS 设置、缓存、规则 |
| 服务器端口无法访问 | 安全组、监听地址、主机防火墙 |
| 证书报警 | 域名匹配、时间、证书链、中间人代理 |
| 浏览器正常但终端失败 | 应用代理参数、环境变量、TUN 路由 |

一次只改变一个变量；绝不要为了排错长期关闭防火墙或忽略证书错误。
