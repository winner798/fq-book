## 全链路总览

```text
应用 / 浏览器
  ↓
操作系统：DNS / 路由 / 系统代理或 TUN
  ↓
本地网络：Wi-Fi / 路由器 / NAT / ISP
  ↓
[直连目标] 或 [本地代理客户端 → 远端代理服务器]
  ↓
目标站点：HTTPS / 应用服务
```

**学习原则**：每章都讲“是什么、为什么、如何验证”，提供可在授权设备上执行的实验和自测题。先以 HTTP/HTTPS 学习完整链路，再理解专业 VPN 与代理方案，而不是一开始执行未知一键脚本。
