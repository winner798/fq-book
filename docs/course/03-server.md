# 第三课：服务器到底是什么？

## 1. 服务器并不神秘

服务器是为其他设备提供服务的计算机或软件。VPS 是云平台提供的虚拟计算环境，通常有 CPU、内存、磁盘和网络接口；并非每台 VPS 都自带可直接入站访问的公网 IPv4。

## 2. 从客户端到服务器需要什么？

```text
本机客户端 → 本地网络/ISP → 云防火墙/安全组 → 服务器网络接口
                                             ↓
                                      主机防火墙 → 监听端口 → 服务进程
```

任何一层不通，都可能表现为“连接超时”。DNS 只把名称指向地址；它不会帮你自动开放端口。

## 3. 首次登录与安全准备

在自己拥有权限的测试 VPS 上，确认公网地址、SSH 登录用户名和私钥。Linux/macOS 终端示例：

```bash
ssh -i ~/.ssh/my_key user@SERVER_IP
uname -a
ip addr
ip route
ss -lntup
```

`SERVER_IP`、`user`、密钥路径均为占位符，不要直接复制使用。Windows 可使用系统自带 OpenSSH。优先使用密钥认证、及时更新系统、仅开放必要端口；确认密钥可登录后再考虑关闭密码登录，避免把自己锁在服务器外。

## 4. 端口与防火墙

- 服务进程必须监听正确的地址和端口。
- 云安全组和主机防火墙是不同层次，可能都需要放行。
- 监听 `127.0.0.1` 只允许本机连接；监听 `0.0.0.0` 通常接受所有 IPv4 接口的连接，但还受防火墙控制。
- 不要为了排障长期关闭全部防火墙或公开管理端口。
