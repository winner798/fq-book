# 06｜云服务器、Linux、SSH、端口与防火墙：从零拥有一台服务器

**本课目标**：理解 VPS 与本地电脑的区别、SSH 登录、监听端口和两级防火墙。第 07/08 课会使用这台机器。

## 什么是 VPS？

VPS（虚拟私有服务器）是云平台提供的隔离计算环境，通常运行 Linux。云平台给你 CPU、内存、磁盘、网络接口以及可能的公网 IP。你在 VPS 上运行服务端程序；你的电脑或手机运行客户端程序。

**这不是“买服务器就自动能上网”**。服务器与目标网站之间能否连接、有哪些端口开放、运行哪个程序，都需要单独验证。

## 入门前的选择

第一次练习建议用现成 Linux 虚拟机熟悉命令，再考虑自有 VPS。云服务器可选 Ubuntu LTS；云厂商账单、地区、流量费、服务条款都应事先了解。

你需要记录**非秘密**信息：公网 IP/域名、Linux 登录用户名、SSH 端口、系统版本。**私钥、登录密码、API Key、节点密码不要放进教程或截图**。

## SSH：从本地安全管理远端

Windows 11 PowerShell 或 Linux/macOS 终端都可以运行 OpenSSH 客户端。

```bash
ssh-keygen -t ed25519 -C "learning-vps"
```

把生成的**公钥**（通常以 `.pub` 结尾）添加到自己云主机的登录账号或云平台；私钥必须留在本地。然后：

```bash
ssh ubuntu@你的服务器公网IP
```

Linux 用户名取决于云镜像，可能是 `ubuntu`、`debian` 或你自己创建的用户。第一次连接要核对主机指纹，不要盲目输入 yes。主机指纹应通过云厂商控制台或可信的带外渠道确认。

## 连接不上时，逐层排查

1. 云服务器是否运行？有没有公网 IP？
2. 云平台**安全组/网络防火墙**是否允许你的来源 IP 访问 TCP 22（或自定义 SSH 端口）？
3. Linux 系统防火墙有没有拦截？
4. SSH 服务是否运行，监听哪个端口？登录账号、公钥和私钥是否匹配？

在 VPS 上通过云控制台查看：

```bash
ip addr
ip route
sudo ss -lntp
sudo systemctl status ssh
```

若 Ubuntu 使用 UFW，**先确认 SSH 已允许再启用防火墙**。示例：

```bash
sudo ufw allow OpenSSH
sudo ufw status verbose
```

不要为了测试就执行 `sudo ufw disable`；云安全组与 Linux 防火墙是两道彼此独立的门。最好将 SSH 入站来源限制为自己的固定 IP 或可信网络；注意移动网络 IP 常变化。

## 用公网网站验证服务器的出站

在已登录的服务器上：

```bash
curl -I https://example.com
ip route
```

能够访问说明这台服务器具有至少一种可用的出站路径；**不代表它已经运行代理服务**。想象第 07 课在此基础上打开 SSH 动态转发，你就能明确知道“客户端和服务器各在何处”。

## 一张完整的检查单

- [ ] 能登录云控制台，即使 SSH 出问题也有救援办法
- [ ] 知道 VPS 公网地址、登录用户名、系统版本
- [ ] SSH 公钥登录成功；私钥妥善保管
- [ ] 知道云安全组和系统防火墙的区别
- [ ] 能用 `ss` 查看监听、用 `curl` 查看出站
- [ ] 已了解云平台流量计费与数据保护

**自测**：开放安全组 443 端口，是否等于 443 就能访问？答：否，服务必须监听，系统防火墙也不能阻断，且协议正确。
